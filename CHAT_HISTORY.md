# История чата с файлами

## ✅ Реализовано

Теперь операторы видят полную историю чата, включая все фото и файлы, которые абонент отправлял ранее!

## 📸 Что видит оператор

При открытии диалога оператор видит:

1. **Все сообщения** - полная история переписки
2. **Все фото** - изображения отображаются прямо в чате
3. **Все файлы** - документы доступны для скачивания
4. **Кнопки бота** - интерактивные кнопки от бота

## 🎯 Как это работает

### При повторном обращении:

1. Абонент открывает чат
2. Система находит предыдущий диалог (если есть)
3. Загружается полная история, включая все attachments
4. Новый оператор видит:
   - Все предыдущие сообщения
   - Все отправленные фото (можно кликнуть для просмотра)
   - Все отправленные файлы (можно скачать)
   - Контекст предыдущего обращения

### Отображение в операторском кабинете:

- **Изображения**: Отображаются как превью (макс. 400px), клик открывает в полном размере
- **Документы**: Отображаются как ссылки с размером файла
- **Кнопки бота**: Интерактивные кнопки для быстрых ответов

## 🔍 Пример использования

1. Абонент отправляет фото проблемы с интернетом
2. Оператор видит фото в истории
3. Диалог закрывается
4. При повторном обращении новый оператор видит:
   - Предыдущее фото проблемы
   - Историю переписки
   - Контекст проблемы

## 📝 Технические детали

- Attachments хранятся в поле `attachments` (JSON) таблицы `messages`
- При загрузке истории все attachments автоматически включаются
- URL файлов формируются автоматически на основе текущего хоста
- Изображения кэшируются браузером для быстрой загрузки

## ⚠️ Важно

- Файлы сохраняются на сервере в папке `backend/uploads/`
- При удалении файлов с сервера они не будут отображаться в истории
- Рекомендуется настроить резервное копирование папки `uploads/`
