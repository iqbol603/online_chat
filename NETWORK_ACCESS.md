# Доступ по локальной сети

## 🚀 Настройка завершена!

Теперь все приложения доступны по локальной сети.

## 📍 Как получить доступ

### 1. Узнайте IP адрес вашего компьютера

**На macOS/Linux:**
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
```

**Или:**
```bash
ipconfig getifaddr en0  # macOS
```

**На Windows:**
```cmd
ipconfig
```
Ищите IPv4 адрес (обычно начинается с 192.168.x.x или 10.x.x.x)

### 2. Запустите приложения

```bash
# Backend (терминал 1)
cd backend
npm run start:dev

# Frontend - Web виджет (терминал 2)
cd frontend
npm run dev

# Operator Panel (терминал 3)
cd operator-panel
npm run dev
```

### 3. Откройте в браузере

После запуска вы увидите в консоли backend ваш локальный IP адрес, например:
```
🚀 Server running on:
   http://localhost:3000
   http://192.168.1.100:3000
```

**Используйте эти адреса:**

#### Web виджет (для клиентов):
- Локально: `http://localhost:3001`
- По сети: `http://192.168.1.100:3001` (замените на ваш IP)

#### Операторский кабинет:
- Локально: `http://localhost:3002`
- По сети: `http://192.168.1.100:3002` (замените на ваш IP)

#### Backend API:
- Локально: `http://localhost:3000`
- По сети: `http://192.168.1.100:3000` (замените на ваш IP)

## 📱 Доступ с мобильных устройств

1. Убедитесь, что мобильное устройство подключено к той же Wi-Fi сети
2. Откройте браузер на мобильном устройстве
3. Введите: `http://ВАШ_IP:3001` (для виджета) или `http://ВАШ_IP:3002` (для операторского кабинета)

**Пример:**
- Если IP вашего компьютера: `192.168.1.100`
- На телефоне откройте: `http://192.168.1.100:3002`

## 🔒 Безопасность

⚠️ **Важно:** Эти настройки предназначены для разработки и локальной сети. 

Для продакшена:
- Используйте reverse proxy (nginx)
- Настройте HTTPS
- Ограничьте CORS только нужными доменами
- Используйте файрвол для ограничения доступа

## 🐛 Решение проблем

### Не могу подключиться с другого устройства

1. **Проверьте файрвол:**
   ```bash
   # macOS - разрешить входящие подключения на портах
   # Системные настройки → Защита и безопасность → Файрвол → Параметры
   ```

2. **Проверьте, что устройства в одной сети:**
   - Оба устройства должны быть подключены к одной Wi-Fi сети

3. **Проверьте порты:**
   ```bash
   # Проверьте, что порты открыты
   lsof -i :3000
   lsof -i :3001
   lsof -i :3002
   ```

### WebSocket не подключается

- Убедитесь, что используете правильный IP адрес
- Проверьте, что backend запущен и доступен
- Проверьте консоль браузера на наличие ошибок CORS
