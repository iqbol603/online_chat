# Загрузка файлов в чате

## ✅ Реализовано

Абоненты теперь могут отправлять фото и файлы в чате!

## 📁 Поддерживаемые форматы

- **Изображения**: JPEG, JPG, PNG, GIF, WebP
- **Документы**: PDF, DOC, DOCX
- **Максимальный размер**: 10MB

## 🎯 Как это работает

### Для абонентов:

1. Нажмите кнопку **📎** рядом с полем ввода
2. Выберите файл (фото или документ)
3. Файл появится над полем ввода
4. Нажмите **Отправить** - файл загрузится и отправится в чат

### Отображение:

- **Изображения** отображаются прямо в чате (можно кликнуть для просмотра в полном размере)
- **Документы** отображаются как ссылки для скачивания

## 🔧 Технические детали

### Backend:

- Файлы сохраняются в папку `backend/uploads/`
- Endpoint для загрузки: `POST /api/messages/upload`
- Статические файлы доступны по пути `/uploads/`

### Frontend:

- Автоматическая загрузка файла перед отправкой сообщения
- Превью выбранного файла
- Валидация размера (макс. 10MB)
- Индикатор загрузки

## 📝 Структура данных

Файлы сохраняются в поле `attachments` сообщения:

```json
{
  "type": "image",
  "url": "/uploads/file-1234567890.jpg",
  "filename": "photo.jpg",
  "size": 102400,
  "mimetype": "image/jpeg"
}
```

## ⚠️ Важно

1. **Папка uploads**: Убедитесь, что папка `backend/uploads/` существует и доступна для записи
2. **Размер файлов**: Ограничение 10MB можно изменить в `messages.controller.ts`
3. **Безопасность**: В продакшене добавьте проверку типов файлов и антивирусное сканирование

## 🚀 Использование

После запуска backend и frontend:

1. Откройте чат-виджет
2. Зарегистрируйтесь или войдите
3. Нажмите кнопку 📎 для выбора файла
4. Выберите фото или документ
5. Отправьте сообщение

Файл автоматически загрузится и отобразится в чате!
