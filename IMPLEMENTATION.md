## 🔧 Технологии

- **Backend**: NestJS, TypeScript, TypeORM, MySQL, Socket.IO
- **Frontend**: React, TypeScript, Vite, Socket.IO Client
- **База данных**: MySQL 8+

## 📝 Примечания

1. **Пароль администратора**: После создания БД нужно сгенерировать правильный bcrypt hash для пароля админа. Используйте скрипт `backend/scripts/create-admin.ts`

2. **Переменные окружения**: Создайте `.env` файл в `backend/` на основе `.env.example`

3. **WebSocket**: Для realtime сообщений используется Socket.IO. Клиенты и операторы подключаются через WebSocket.

4. **Безопасность**: В продакшене обязательно:
   - Отключите `synchronize: true` в TypeORM
   - Используйте сильные пароли
   - Настройте HTTPS
   - Добавьте rate limiting
   - Настройте CORS правильно
