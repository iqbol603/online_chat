# Операторский кабинет

## Запуск

```bash
cd operator-panel
npm install
npm run dev
```

Откройте `http://localhost:3002` в браузере.

## Вход в систему

**Тестовые данные:**
- Email: `admin@example.com`
- Пароль: `admin123`

## Функционал

### 1. Вход и статус
- Вход по email и паролю
- Управление статусом: Онлайн / Отошёл / Офлайн
- Автоматическое подключение к WebSocket при входе

### 2. Очередь диалогов
- Видит все диалоги в статусе `queued`
- Показывает время ожидания клиента
- Может принять диалог из очереди (кнопка "Принять")

### 3. Активные диалоги
- Видит все свои активные диалоги (статус `in_progress`)
- Может переключаться между диалогами
- Показывает информацию о клиенте (имя, телефон, канал)

### 4. Переписка
- Видит историю сообщений
- Может отправлять сообщения клиентам
- Realtime обновления через WebSocket
- Автопрокрутка к новым сообщениям

### 5. Управление диалогами
- Закрытие диалога
- Автоматическое обновление списка очереди

## Интерфейс

### Левая панель
- **Очередь** - новые диалоги, ожидающие оператора
- **Активные** - текущие диалоги оператора

### Правая панель
- Информация о клиенте
- История переписки
- Поле ввода сообщения
- Кнопка закрытия диалога

## WebSocket события

Оператор подключается к WebSocket и получает:
- `conversations:queued` - обновление очереди
- `conversations:active` - активные диалоги
- `message:new` - новое сообщение
- `messages:history` - история при открытии диалога

Оператор отправляет:
- `operator:register` - регистрация при подключении
- `operator:accept` - принятие диалога из очереди
- `operator:message:send` - отправка сообщения
- `operator:close` - закрытие диалога
